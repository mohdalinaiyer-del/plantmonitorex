Biography
A short story about why I built the Smart Plant Monitoring System.
My journey

My name is Mohamed, and this project represents more than just a school assignment — it’s a problem I genuinely wanted to solve. I’ve always been fascinated by how technology can make everyday life easier, and I noticed something simple: people forget to water their plants. Sometimes they water too much, sometimes too little, and the plant suffers quietly. I wanted to fix that.

That’s where the idea for the Smart Plant Monitoring System began.

I started by learning how soil moisture sensors work, how temperature affects plant health, and how microcontrollers like Arduino can read real‑world data. At first, nothing worked the way I expected. The sensor readings were unstable, the wiring confused me, and the code felt impossible. But every time something broke, I learned something new.

Slowly, the system came to life. I built a setup that could measure soil moisture and temperature, send the data to a computer, and display it on a live dashboard. Then I pushed myself further — adding graphs, alerts, dark mode, and even a QR code so anyone can access the project online.

This project taught me more than electronics and coding. It taught me patience, problem‑solving, and the feeling of watching an idea turn into something real.

In the future, I want to expand this system with automatic watering, mobile notifications, and maybe even AI‑based plant health predictions. This is just the beginning — and I’m excited to keep building.

Project Presentation
A web version of the main points from my Smart Plant Monitoring System presentation.

1. Introduction

The Smart Plant Monitoring System is designed to help people take better care of their plants by tracking soil moisture and temperature in real time. It combines sensors, a microcontroller, and a web dashboard to make plant care easier and smarter.

2. Problem Statement

  • Plants are often underwatered or overwatered.
  • People don’t always know when their plants are stressed.
  • Manual checking is time‑consuming and not always accurate.

3. Proposed Solution

Use a soil moisture sensor and temperature sensor connected to an Arduino to collect data, then send it to a computer and display it on a live dashboard with alerts, graphs, and a clean interface.

4. Components Used

  • Arduino board
  • Soil moisture sensor
  • Temperature sensor
  • USB connection to computer
  • HTML, CSS, and JavaScript for the dashboard

5. How It Works

  • Sensors measure soil moisture and temperature.
  • Arduino reads the sensor values and sends them over USB.
  • The website reads the serial data using the Web Serial API.
  • Values are displayed, graphed, and checked for warnings.

6. SDG Connection

This project supports sustainability by helping reduce water waste and improving plant health, which connects to goals related to responsible consumption and climate action.

7. Benefits

  • Helps users know exactly when to water plants.
  • Prevents overwatering and underwatering.
  • Provides a clear visual dashboard for plant health.
  • Can be expanded with more features in the future.

8. Conclusion

The Smart Plant Monitoring System shows how simple sensors and code can solve real‑world problems. It is a starting point for more advanced smart gardening systems and demonstrates my interest in combining technology with sustainability.
